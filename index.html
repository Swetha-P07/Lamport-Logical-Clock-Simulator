4. Consistent Logical Ordering

Events are sorted by Lamport timestamp, then process ID as a deterministic tie-breaker. Equal timestamps do not necessarily mean events are causally related.

5. Lamport Clock Rules

  1. Initially, every process clock is 0.
  2. For an internal event, increment the local clock by 1.
  3. For a send event, increment the sender clock by 1 and attach that timestamp to the message.
  4. For a receive event carrying timestamp T, set clock = max(local clock, T) + 1.
  5. Sort the event list by timestamp; use process ID to break display ties.
